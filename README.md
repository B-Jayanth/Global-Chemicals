# Global Chemicals LLC — Operations Dashboard

### Modern UI/UX Design • Frontend Development • Responsive Web Design

A modern, professional business operations dashboard designed for **Global Chemicals LLC**, featuring a clean corporate interface, intuitive navigation, consistent branding, and interactive dashboard components.

This project showcases my frontend development and UI/UX design skills through a business-oriented interface that balances visual appeal, usability, accessibility, and responsive design.

## ✨ Project Preview

A corporate dashboard experience built around a distinctive orange-and-blue brand identity, organized layouts, and streamlined navigation.

> **Design philosophy:** Clean interfaces. Clear hierarchy. Consistent design. Better user experiences.

## 🎨 UI/UX Design Highlights

- **Corporate Visual Identity:** Custom branding using the Global Chemicals LLC logo and a cohesive colour system.
- **Modern Dashboard Layout:** Structured content areas designed to improve readability and information hierarchy.
- **Intuitive Sidebar Navigation:** Collapsible navigation groups with clear labels and organized business modules.
- **Consistent Iconography:** Purposeful icons that improve navigation clarity and visual consistency.
- **Professional Typography:** Carefully structured headings, labels, and body text for readability.
- **Visual Hierarchy:** Strategic use of colour, spacing, contrast, and alignment to emphasize important information.
- **Reusable UI Patterns:** Consistent styling for cards, navigation items, buttons, forms, and content sections.
- **Interactive Components:** Expandable menus, navigation states, and follow-up reminder workflows.
- **Responsive Design:** Layouts designed to adapt to desktop, tablet, and mobile screen sizes.

## 🟠 Brand Colour System

The interface follows a consistent four-colour design system inspired by the company logo.

| Colour | Hex | Design Purpose |
|---|---|---|
| Vibrant Orange | `#F06B36` | Primary actions, highlights, and visual accents |
| Corporate Blue | `#1D4499` | Branding, navigation, and prominent headings |
| Light Grey | `#F4F5F7` | Page backgrounds and content surfaces |
| Charcoal | `#22252A` | Text, labels, and supporting content |

This palette maintains brand consistency while providing clear contrast between interactive elements, backgrounds, and text.

## 🧩 Interface Design & Components

### Dashboard
A centralized interface for presenting business information through organized sections and reusable visual components.

### Sidebar Navigation
A collapsible navigation system organized into five functional groups:

- **Sales:** Clients & Contacts, Leads & Opportunities, Follow-ups & Activities
- **Commercial:** Quotations, Sales Orders
- **Delivery:** Projects, Tasks & Calendar
- **Finance:** Invoices, Payments & Collections
- **Manage:** Alerts & Escalations, Reports & Analytics, User Management, Settings

### Interactive Workflows
Interface elements support intuitive navigation and follow-up management, including workflows for preparing email reminders for due and overdue activities.
